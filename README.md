## 🚀 Sobre o Projeto

A **Voccatio Tech** nasceu da convicção de que tecnologia e estratégia só geram valor real quando aliadas à disciplina do método. Este repositório contém o código-fonte do website institucional da empresa, projetado com foco em alta performance, tipografia técnica e acessibilidade visual.

O objetivo principal desta interface é apresentar de forma clara e transparente o portfólio de soluções da Voccatio:
* Desenvolvimento e engenharia de software sob medida;
* Criação de websites institucionais e portais corporativos;
* Mentoria e consultoria estratégica em processos e tecnologia;
* Identidades visuais e tradução de artigos técnicos.

---

## ✨ Funcionalidades

- [x] **Arquitetura Semântica & Acessível:** Estrutura HTML5 moderna, com suporte a leitores de tela e metadados Open Graph.
- [x] **Carrosséis Nativos & Interativos:** Seções dinâmicas para exibição de serviços e depoimentos de clientes.
- [x] **Formulário de Contato Direto:** Validação front-end pronta para integração com APIs de envio e automação comercial.
- [x] **Design Responsivo & Identidade Visual:** Layout adaptado a qualquer dispositivo, alinhado à paleta Navy & Slate Gray da marca.
- [ ] **Integração com Webhook/API:** Disparo automático de leads diretamente para CRM (Em desenvolvimento).
- [ ] **Modo Dark/Light Alternável:** Toggle nativo de tema via variáveis CSS (Planejado).

---

## 🛠 Tecnologias Utilizadas

O projeto adota uma stack limpa e enxuta, priorizando tempo de carregamento e facilidade de manutenção:

* **HTML5:** Marcação semântica estruturada.
* **CSS3 Moderno:** Flexbox, CSS Grid, Custom Properties (variáveis) e animações leves.
* **JavaScript (ES6+):** Manipulação dinâmica de DOM para navegação mobile e componentes de carrossel sem dependências externas pesadas.
* **Google Fonts:** Tipografias *Space Grotesk* (títulos/marcação técnica) e *Inter* (leitura contínua).

## ⚙️ Pré-requisitos

Para clonar e testar localmente este repositório, você precisará de:

* [Git](https://git-scm.com/) instalado em seu sistema operacional;
* Um navegador web moderno (Chrome, Firefox, Safari ou Edge);
* *(Opcional)* Extensão **Live Server** (VS Code) ou o utilitário `npx serve` para servir arquivos estáticos localmente.
